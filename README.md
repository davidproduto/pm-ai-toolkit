# PM + IA Toolkit

Um repositório com templates, skills e estudos de caso que uso no meu dia a dia como Product Manager, apoiado por ferramentas de IA (LLMs) para acelerar decisão orientada a dado.

A ideia não é "falar sobre IA em produto" — é mostrar o método e as ferramentas que uso de verdade: como transformo tickets de suporte em priorização, como escrevo um PRD a partir de dados brutos, como cruzo squads/times com dados de uso real antes de decidir o que entra na sprint.

> Todos os dados e exemplos neste repositório são fictícios ou anonimizados. Nenhuma informação proprietária de qualquer empresa é usada aqui.

## Estrutura

```
/templates       → Documentos que uso para especificar e decidir (PRD, RFC, decision log, experiment brief)
/skills           → Fluxos reutilizáveis de "PM aumentado por IA" (análise de tickets, priorização por dados, personas sintéticas)
/case-studies     → Exemplos completos: problema → dado → decisão → resultado
```

## Como usar

1. Comece pelos templates em `/templates` — são ponto de partida para qualquer decisão de produto que eu documento.
2. Veja `/skills` para os fluxos que uso com ferramentas de IA (ex: Claude, ChatGPT) para acelerar tarefas repetitivas de PM.
3. Veja `/case-studies` para um exemplo de ponta a ponta de como uso esse método na prática.
