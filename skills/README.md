# Skills: PM aumentado por IA

Cada pasta aqui é um fluxo reutilizável — um "prompt + processo" que uso para acelerar uma tarefa recorrente de PM. Não são produtos prontos, são métodos: o valor está em adaptar o prompt ao seu contexto e dados reais.

## Skills incluídas

1. **[support-ticket-pattern-analysis](./support-ticket-pattern-analysis.md)** — transforma uma exportação de tickets de suporte em padrões de bug agrupados, com causa raiz sugerida e critério de aceite, prontos para virar item de backlog.
2. **[data-informed-prioritization](./data-informed-prioritization.md)** — cruza backlog com dados de uso (analytics) e volume de suporte para gerar um ranking de prioridade defensável.
3. **[synthetic-persona-from-tickets](./synthetic-persona-from-tickets.md)** — cria uma "persona" com voz real de usuário a partir de um volume grande de tickets/feedback, para testar hipóteses de produto rapidamente sem esperar pesquisa formal.

## Princípio comum

Toda skill aqui segue o mesmo formato:
- **Input:** o que você precisa ter em mãos
- **Prompt/processo:** o passo a passo (ou prompt literal) que uso
- **Output esperado:** o que deve sair no final
- **Limite:** o que isso NÃO substitui (pesquisa qualitativa real, validação com cliente, etc.)

IA acelera o "primeiro rascunho" de raciocínio — a decisão final continua sendo humana.
